Prescription Extractor SaaS

Built an AI-powered healthcare solution that extracts structured medical information from prescriptions using OCR, NLP, OpenCV, and FastAPI while improving data accessibility and accuracy.

// Project Overview

Enterprise-grade AI healthcare SaaS platform that digitizes handwritten and printed medical prescriptions using OpenCV image preprocessing, Tesseract OCR, FastAPI, PostgreSQL, enterprise analytics, advanced medical field extraction, intelligent filtering, and automated reporting for hospitals, clinics, and pharmacies.

Problem Statement

Hospitals and pharmacies waste thousands of hours manually transcribing patient prescriptions, leading to human errors, lost data, and inefficient clinical workflows. Poorly lit images and doctor shorthand drastically corrupt traditional software.

Solution Architecture

Integrated OpenCV Deskew filters, Contrast enhancements, and Tesseract OCR with fuzzy matching algorithms mapped against a PostgreSQL core to confidently verify dosage and medicine interactions.

// Core Processing Pipeline

OpenCV Image Processing

Adaptive thresholding, Deskew filters, noise cancellation, and QR code detection for poor quality scans.

Tesseract OCR & NLP

Fuzzy dictionary matching extracting 25+ structured fields including doctor metadata and active medicine.

Enterprise Filter Engine

Full-text search, pagination, and multi-factor filtering built natively into the frontend and PostgreSQL DB.

Analytics Dashboard

Clinical overview aggregating CSV, PDF, and Excel mass exports, confidence scoring flags, and duplicates.

// DevOps & System Architecture

FastAPI Backend Endpoints

High-performance REST APIs handle parallel asynchronous uploads, data validation routing, and automated structured reports (JSON/PDF).

PostgreSQL Database Layer

Enterprise relational schema mapped with SQLAlchemy ORM handling rapid data retrieval and audit-ready data structures.

Docker Deployment & Optimization

Containerized Python backend. Added async sub-process execution which slashed OCR processing time down to sub-2 second windows under max load.

Phase 6 Enterprise Testing & Future Roadmap

Thorough load testing completed. Future pipeline plans cross-reference global drug interaction graphs for real-time risk alerts and direct HL7/FHIR EHR integrations.
